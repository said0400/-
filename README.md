# 🎬 Video Script Generator + AI Voiceover

Turn any raw idea into a **professional 30–80 second video script** using **Groq (LLaMA 3.3 70B)**, then synthesize it into a polished voiceover using **Google Gemini TTS**.

---

## ✨ Features

- ✅ Generates structured scripts: Hook → Body → CTA
- ✅ **Enforces 30–80s duration with real word-count measurement + auto-retry**
- ✅ 5 tone options: energetic, inspirational, educational, humorous, calm
- ✅ 5 voice options via Gemini TTS
- ✅ Outputs WAV audio files ready for video editing
- ✅ `--script-only` mode for text-only use

---

## 🚀 Quick Start

### 1. Clone the repo
```bash
git clone https://github.com/YOUR_USERNAME/video-script-generator.git
cd video-script-generator
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Set API keys
```bash
# Linux / macOS
export GROQ_API_KEY="your_groq_api_key_here"
export GEMINI_API_KEY="your_gemini_api_key_here"

# Windows PowerShell
$env:GROQ_API_KEY="your_groq_api_key_here"
$env:GEMINI_API_KEY="your_gemini_api_key_here"
```

Get your keys:
- Groq → https://console.groq.com/keys
- Gemini → https://aistudio.google.com/app/apikey

### 4. Run
```bash
# Full pipeline: script + voiceover
python main.py "Why drinking water first thing in the morning changes your energy"

# Custom tone and voice
python main.py "The secret to waking up at 5am" --tone inspirational --voice female_warm --output morning_video

# Script only (no audio)
python main.py "Top 3 productivity hacks for remote workers" --script-only
```

## ⏱️ How Duration Enforcement Works

1. Script is generated by Groq LLaMA 3.3 70B
2. Word count is measured locally (not trusted from the model)
3. Duration estimated at **150 words/minute** (real speaking pace)
4. If outside 30–80s → model is retried with specific feedback (up to 3 attempts)
5. If still too long after retries → hard-trimmed to 200 words
